# Demo spectacle amp

## Goal
Make the MorePass playground feel cinematic and high-energy on first viewport: brand-led, kinetic atmosphere, luminous stage, without clutter or competitor naming.

## In scope
- Visual redesign of `demo/index.html` (atmosphere, brand, stage, chrome)
- Intro / ambient motion in `demo/main.ts` that showcases MorePass itself
- Keep all existing demo APIs reachable; no nested scrollbars; expand-in-panel UX unchanged

## Out of scope
- Core library API changes
- Remote push / go-live

## Acceptance
- First viewport reads as one composition with MorePass as hero
- Controls, stage, and code remain fully visible after intro
- At least 2–3 intentional ambient/intro motions
- No GSAP or competitor names in copy
